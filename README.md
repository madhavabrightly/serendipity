# Nameera Shahid — Portfolio 2.0 (Ultra Beast Edition)

🔥 A max-ultra advanced portfolio website with 1000+ lines per file, particle systems, moisture simulation, and next-level animations.

## 🚀 Features

- **Particle System** — 150+ connected particles with mouse repulsion physics
- **Moisture Simulation** — Rain drops with gravity, tails, and ripple effects on impact
- **Dot Spread Effect** — Random dot bursts that spread and fade across the screen
- **Typed Text Engine** — Multi-word typewriter effect with delete/retype cycle
- **Custom Cursor** — Animated cursor with trailing ring and hover scaling
- **Scroll Progress Bar** — Gradient progress bar tracking page scroll
- **Scroll Reveal** — Elements animate in as you scroll with staggered delays
- **Dark/Light Mode** — Full theme toggle with localStorage persistence
- **Project Filter** — Filter projects by category (Python, Web, API, All)
- **Testimonials Carousel** — Auto-rotating testimonials with dot navigation + swipe support
- **Skill Progress Bars** — Animated progress bars on scroll reveal
- **Counter Animation** — Hero stats count up on view
- **Glitch Text** — CSS glitch effect on hover elements
- **Floating Shapes** — Ambient background shapes with float animation
- **Grain/Noise Overlay** — Subtle film grain texture for depth
- **Contact Form** — Full validation + submit simulation with loading/error states
- **Quote Generator** — Fetch motivational quotes from API with category filter
- **Parallax Effect** — Hero image follows mouse movement
- **Loading Screen** — Animated ring spinner on page load
- **Scroll to Top** — Floating button appears after scrolling down
- **Keyboard Shortcuts** — T = theme toggle, H = scroll home, Esc = close menu
- **Konami Code** — Secret easter egg (↑↑↓↓←→←→ba)
- **Mobile Responsive** — Fully adaptive layout with hamburger menu + swipe gestures
- **Reduced Motion Support** — Detects prefers-reduced-motion and disables animations
- **Light/Dark Mode** — 100+ lines of light mode overrides
